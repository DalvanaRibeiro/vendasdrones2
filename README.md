# Academia Comercial — Pilotagem de Drones

Site independente e estático, pronto para GitHub Pages. O arquivo `index.html` contém todo o CSS, JavaScript e a imagem do drone incorporados.

## Publicação
1. Crie um repositório no GitHub.
2. Envie `index.html` à raiz.
3. Em Settings → Pages, selecione Deploy from a branch, `main`, `/(root)`.
